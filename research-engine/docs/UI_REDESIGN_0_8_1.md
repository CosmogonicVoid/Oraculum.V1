# Oraculum 0.8.1 UI update

Close the running server terminal. Extract Oraculum-UI-Update-0.8.1.zip into the existing project folder containing run.cmd, allowing file replacement. Run run.cmd again and refresh the browser. Do not extract it into the inner Python package folder. No data reset or model setup is required.

Overview puts the ranked shortlist and three counts first. Coverage information is folded; report problems remain expanded. Research combines navigation for saved evidence/AI briefs and news; report links preserve their evidence cutoff. Current news remains explicitly labelled as the current collection. Legacy URLs continue working. Stock pages put cautions alongside score and financial evidence.

The app uses local system fonts, CSS and HTML, without external assets or new dependencies. Narrow screens use wrapping navigation and a single-column stock view. No synthetic price chart was added: the saved report does not expose a chart-ready series through this view. Existing price diagnostics remain available.

Scores, eligibility, timestamps, stored data, Qwen settings and scheduled workflows are unchanged. Opening pages never starts AI or refresh jobs. Browser visual QA and native Windows execution were not available; automated HTTP, HTML, read-only and regression checks cover behavior. This release does not claim improved market prediction accuracy.
