# Oraculum 0.8.3 — Graphite glass

Install over 0.8.2: close the server, extract the update into the folder containing run.cmd, replace files, restart run.cmd, then refresh the browser.

Graphite surfaces with translucent backgrounds and background blur where supported. Opaque text, subtle borders and high-contrast financial values preserve readability. Hover, keyboard focus and press states give controls responsive feedback. Coarse-pointer controls have larger touch targets. Reduced-motion preferences suppress animation; reduced-transparency preferences use solid surfaces. Browsers without backdrop-filter get solid panel fallbacks. No JavaScript, external assets or new dependencies were added.

This is a visual theme update. It does not add the still-missing historical stock-price charts. Research calculations, data and local model configuration are unchanged. Automated regression and patch checks cover functionality; browser visual and native Windows checks were unavailable.
